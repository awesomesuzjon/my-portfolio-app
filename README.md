# Personal Portfolio Website

A modern, responsive portfolio website designed to showcase my professional experience, technical skills, projects, and academic work in software development and cybersecurity.

The portfolio serves as a central platform for highlighting my background as a Software Engineer and Master of Information Technology (Cyber Security) student, featuring selected projects, technical expertise, and career achievements.

## Features

* Responsive modern UI/UX
* Project showcase section
* Skills and technology overview
* Professional experience timeline
* Education and certifications
* Contact and networking links
* Dark/light theme support
* Interactive animations and components

## Technology Stack

### Frontend

* Next.js 15
* React 18
* TypeScript
* Tailwind CSS 4

### UI Components

* Radix UI
* Lucide React
* Sonner
* Vaul
* Embla Carousel

### Forms & Validation

* React Hook Form
* Zod

### Analytics

* Vercel Analytics

## Purpose

This portfolio was created to demonstrate my expertise in software development, web technologies, and cybersecurity while providing a professional online presence for recruiters, employers, and collaborators.
